# BNO 定居/入籍申請助手

BNO簽證出入境日誌 / ILR·入籍缺勤計算 / PDF報告工具。純本機運行,冇伺服器,資料只存喺你部裝置嘅瀏覽器入面。除咗自我參考,呢個app亦設計嚟做ILR、入籍(BC)正式申請嘅輔助文件。

## 點樣開始用

**方法一:直接開(最簡單)**

雙擊 `index.html`,用瀏覽器打開就得。呢個方法下,大部分功能(記錄、計算、PDF生成同儲存、備份匯出/匯入)都正常運作。

**方法二:本機伺服器(想用齊PWA功能,例如加到手機主畫面、離線使用)**

Service Worker(離線支援)同「加到主畫面」呢啲功能,瀏覽器規定一定要用 `https://` 或者 `localhost` 先啟用,單純用 `file://` 打開係唔會生效嘅(但唔影響其他核心功能)。想試齊呢部分,可以喺呢個資料夾入面開個簡單本機伺服器,例如:

```
python3 -m http.server 8080
```

然後用瀏覽器開 `http://localhost:8080/`。如果想上手機用,可以將呢個資料夾放上自己嘅網頁空間(或者用 `npx serve` 呢類工具),用 https 網址喺手機瀏覽器開,再揀「加到主畫面」。

**方法三:GitHub Pages(免費、有正式https網址,PWA功能全部生效)**

呢個project已經用relative path寫晒(`js/app.js`、`css/styles.css`咁樣,冇用`/js/app.js`開頭),所以直接放上GitHub Pages就得,唔使改任何code。呢個資料夾已經幫你`git init`好同做咗第一個commit,你淨係需要:

1. 喺GitHub開一個新repo(唔好勾「Add a README」,因為本機已經有一個,避免merge衝突),copy低個repo嘅網址(例如 `https://github.com/<你嘅帳戶>/<repo名>.git`)。
2. 喺呢個資料夾入面(終端機/command line)執行:
   ```
   git remote add origin https://github.com/<你嘅帳戶>/<repo名>.git
   git branch -M main
   git push -u origin main
   ```
3. 上GitHub個repo度,入 Settings → Pages,Source揀「Deploy from a branch」,Branch揀`main`、資料夾揀`/ (root)`,撳Save。
4. 等1-2分鐘,個網站會喺 `https://<你嘅帳戶>.github.io/<repo名>/` 出現。

**要留意嘅嘢**:

- GitHub免費帳戶嘅Pages預設要求repo係public,即係呢份**程式碼**任何人都睇到。因為呢個app冇後台、資料淨係存喺你自己嗰部裝置嘅瀏覽器(IndexedDB),唔會傳去任何伺服器,所以公開code本身唔會洩漏你填嘅個人資料——會公開嘅淨係呢個計算工具嘅程式邏輯/UI。如果你連呢part都唔想公開,就要用GitHub Pro/Team嘅private repo(有月費)。
- 用GitHub Pages版本同用`file://`直接開,係**兩個分開嘅瀏覽器儲存空間**(唔同origin),裡面嘅資料唔會自動同步。想兩邊都用嘅話,記得用「輸出備份」分頁嘅匯出/匯入JSON嚟過渡資料。
- 之後有code更新,想攞返新zip嘅內容覆蓋返個repo,可以直接複製新檔案落去,再 `git add -A && git commit -m "update" && git push`。

## 7個分頁

- **總覽**:成個app嘅狀態儀表板,一眼睇晒有冇超出規定、幾時到期、幾時可以申請 —— 唔顯示逐程離境紀錄。分兩大板塊:ILR(合資格日/最早可遞交日/歷史最高12個月缺勤/合規狀態)同BC/入籍(路線、最早可遞交日、「假設申請日」輸入框、過去N年缺勤、過去12個月缺勤、合規狀態),底下再放稅務/考試提示(FIG窗口、英文試/Life in the UK到期)。「假設申請日」就喺呢度就近輸入,同PDF入籍報告共用同一個值,兩邊數字永遠一致。
- **離境日誌**:記錄離境/返英日期(兩者都必填,未成行可以打勾標記做「預計日期」),仲有離境/返英航班編號(選填)同備註(選填,會印落PDF,建議用英文輸入)。自動計算每程缺勤日數(離境同返英當日都唔計,跟足官方「整日制」規則)。每筆紀錄都有一個「同行者」掣,隨時可以將呢程行程複製去其他檔案(例如同你一齊出遊嘅家人嘅檔案)—— 揀晒想複製去嘅檔案,會幫佢哋各自新增一筆一樣嘅獨立紀錄,之後編輯/刪除唔會連動,如果打錯要逐個檔案自己改;複製成功之後個掣會變做「已複製」並且disable咗,防止手多click幾下整多咗重複紀錄,想再複製多次可以重新開返個視窗。如果新增/編輯嘅行程同表入面其他行程日期重疊,會即時顯示橙色提示文字話你知,同時表格入面重疊嘅紀錄會用橙色底標記,並喺表頂顯示重疊組數摘要 —— 呢個純粹係提醒你check清楚係咪打錯日期,唔會阻止你儲存,亦唔會影響缺勤計算(缺勤計算本身已經用「合併重疊區間」嘅方式處理,唔會因為重疊而重複計算)。手機等窄螢幕會自動將紀錄列表由表格轉做逐筆卡片顯示(標籤+數值一行行列,冇填嘅航班/備註唔顯示空白行),唔使再靠橫向scroll先撳到編輯/同行者/刪除掣。
- **基本資料**:輸入檔案名稱、護照號碼(選填)、簽證生效日、首次抵英日、配偶是否英籍、ILR實際批出日。呢啲資料驅動晒「總覽」分頁嘅全部計算。護照號碼純粹方便同PDF報告內文/檔案名核對,留空唔會影響用其他功能,但會用橙色文字提醒你未填。
- **稅務/考試**:FIG 4年豁免窗口(填「首個成為英國稅務居民嘅稅年」;如果留空,會根據「首次抵英日」用SRT「第一個自動居民測試」183日門檻自動預填一個建議稅年 —— 呢個純粹係假設抵英後一直留喺英國嘅粗略估算,唔係實際SRT判定,你可以隨時自行覆蓋,實際情況例如中途返香港、split year treatment等請自行核對)。英文試(SELT)/Life in the UK 到期提示,兩者而家分開設定:英文試預設有效年期兩年(根據Home Office guidance,SELT證書遞交申請當日一般唔可以超過2年);Life in the UK測試預設無限期(現行官方caseworker guidance冇註明到期日)。兩個年期都可以喺「參數設定」自行調整。呢度仲有一句年齡豁免提示:根據Home Office指引,18歲以下及年滿65歲或以上人士可獲豁免考試,60-64歲嘅申請人特定情況下都可能獲酌情豁免(詳情請向政府查詢)。
- **輸出報告**:分開生成兩種PDF報告 —— ILR報告(只含出入境紀錄同180日滾動缺勤檢查)同BC報告(只含出入境紀錄同入籍專用嘅「過去N年」/「過去12個月」缺勤檢查),刻意唔混喺同一份文件,避免將兩套獨立規則睇錯。表格包含離境日、返英日、缺勤日數、離境/返英航班編號同備註,橫向(landscape)A4排版。報告開首嘅「Name」下面,如果填咗護照號碼會加多一行「Passport No」,方便Home Office核對(冇填就唔會顯示呢行)。用瀏覽器嘅「儲存檔案」視窗揀儲存位置(唔支援嘅瀏覽器會自動fallback做標準下載)。報告內容刻意保持簡潔專業,淨係列出出入境事實同計算方法,唔會加唔必要嘅免責字眼。
- **參數設定**:頂部多咗一張「外觀」卡,可以揀色系(柔和藍/鼠尾草綠/暖沙杏桃,3款都有淺色/深色兩個版本)同埋淺色/深色點揀(跟裝置、或者自己手動指定淺色/深色,唔理裝置設定)。揀咗即時生效,唔使撳「儲存」。呢個係成個app嘅外觀設定,存喺瀏覽器嘅localStorage,唔跟個別檔案(profile)分開,換檔案都唔會變。下面先係原本嘅日數/年期上限,全部可以自己改(包括ILR、入籍非配偶/配偶兩條路線、英文試/Life in the UK有效期、FIG年期),唔會硬寫死喺程式入面。
- **輸出備份**:講清楚資料而家存喺邊(IndexedDB,淨係呢個瀏覽器入面),匯出/匯入 JSON,匯入唔會覆蓋現有資料,會加做新檔案。另外有「清除本機所有資料」一鍵掣,適合喺公用電腦或者交還借用電腦之前用嚟保障私隱 —— 會刪走呢個瀏覽器入面全部檔案、全部行程紀錄同全部參數設定,需要打「刪除」兩個字確認先會生效,動作唔可以還原。

另外,右上角可以新增/切換多個檔案,方便幫全家人分別建立獨立記錄。

### PDF報告入面嘅備註同航班編號

- **備註**:會直接印落PDF,建議用英文輸入。如果打咗中文/非拉丁字母,PDF入面會用提示文字(要求重新用英文輸入)頂住原文,唔會顯示亂碼 —— 呢個處理方式同「檔案名稱」一致。
- **航班編號**:純粹方便交叉核對出入境紀錄,選填,同樣建議用英文/數字輸入(例如 `CX250`)。
- **免責字眼**:PDF只保留「缺勤計算跟足『整日制』規則」呢類方法交代同各報告嘅涵蓋範圍說明,已經刪走「僅供個人參考」、「請自行核對」呢類保護性字眼 —— 由Home Office自行判斷內容,呢個app唔需要幫佢哋作結論。

### PDF檔案名格式

檔案名跟足呢個格式:`{檔案名稱}-{護照號碼}-{ILR或BC}-Absence_Report-{生成日期,YYYY-MMM-DD}.pdf`,例如 `Kwun_Wai_WONG-H12345678-ILR-Absence_Report-2026-SEP-20.pdf`(空格會轉底線,月份用英文縮寫大寫)。護照號碼淨係選填,冇填就直接省略嗰一段,唔會留低多餘嘅連字號。

**注意(瀏覽器限制)**:如果「檔案名稱」用咗中文/非拉丁字母,喺支援「另存新檔」揀位(File System Access API,大部分桌面版Chrome/Edge)嘅瀏覽器,檔案名會正常顯示中文;但部分瀏覽器(例如Firefox、Safari,或者揀位視窗唔支援嘅情況)會fallback做標準下載,而呢類下載喺某啲瀏覽器版本入面,中文檔案名有機會唔生效、變返做瀏覽器通用嘅「download.pdf」—— 呢個係瀏覽器download屬性本身嘅限制,唔係呢個app計錯,PDF內容本身唔受影響,淨係檔案名可能要你自己手動改返。想確保檔案名一定顯示晒,建議「檔案名稱」用英文/拼音輸入(反正PDF報告本身都要求英文名先會顯示,唔會顯示中文)。

### 入籍(Naturalisation)450日規則點計?

根據 gov.uk《Naturalisation as a British citizen by discretion》官方指引,合資格期嘅起始日計法係「申請日 − 年期 + 1日」(例如申請日2022-09-01、5年期,起始日就係2017-09-02),呢個app已經跟足呢個公式,並且用官方例子驗證過(見`tests/run.js`)。缺勤限制覆蓋成個合資格期,包括攞到ILR之前嘅居留期都計埋。

### FIG稅年建議點計?

根據英國 Statutory Residence Test(SRT)嘅「第一個自動居民測試」,喺一個稅年(4月6日至翌年4月5日)入面逗留183日或以上就自動被視為該稅年嘅稅務居民。呢個app會用「首次抵英日」到嗰個稅年尾(4月5日)嘅日數同183比較,粗略估算你第一個稅務居民稅年係邊個。呢個純粹係輔助預填,假設抵英後一直留喺英國冇再出境,亦冇考慮ties test、split year treatment等SRT其他因素,唔係實際SRT判定,你隨時可以自行覆蓋,亦建議向會計師確認實際情況。

## 注意事項

- 呢個工具嘅計算結果**僅供個人參考,並非法律或稅務意見**。正式遞交 ILR、入籍或稅務申報前,請自行核對 gov.uk 最新指引,或諮詢註冊移民顧問/會計師。
- PDF 報告嘅「Name」一欄會直接顯示你嘅「檔案名稱」。如果個名用咗中文/非拉丁字母,PDF入面會顯示提示文字要求你改用英文/拉丁字母填寫(因為PDF字型唔支援中文顯示,避免出現亂碼)。
- 資料淨係存喺你打開緊嗰個瀏覽器入面(IndexedDB)。清除瀏覽器資料、換瀏覽器或者換裝置都會令資料消失,請記得定期用「輸出備份」分頁匯出JSON做保存。

## 開發者資訊(測試)

`tests/run.js` 係核心日期/缺勤計算邏輯嘅單元測試(純 Node,冇依賴):

```
node tests/run.js
```

`tests/e2e.js` 用 Playwright 行過一次主要使用流程(需要已安裝 `playwright` 套件):

```
node tests/e2e.js
```
